# Project Memory Vault

This directory holds concise, durable project context for future sessions. Keep it factual, nonduplicative, and linked to the repository evidence that supports it. The repository instructions in [`AGENTS.md`](../../AGENTS.md) define the source-of-truth hierarchy and update protocol.

## Records

- [`CURRENT_STATE.md`](CURRENT_STATE.md): verified repository state, current planning position, constraints, and next action.
- [`DECISIONS.md`](../../DECISIONS.md): the canonical architecture decision register; update it when an approved decision changes.
- [`IMPLEMENTATION_ROADMAP.md`](../../IMPLEMENTATION_ROADMAP.md): the canonical proposed sequencing and phase exit criteria.

Keep approved decisions in `DECISIONS.md`, not duplicated here. Update current state after meaningful work, and distinguish verified facts from proposals and unresolved questions. Do not store credentials, private user data, unsupported claims, or temporary conversation history.
