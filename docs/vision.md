# vision

`lain.` is a local layer that keeps projects, tools, models, memory, and development workflow together.

It should feel less like an app and more like something that quietly lives on the machine and handles whatever is needed.

## principles

- local first
- simple on the surface
- useful before impressive
- reversible changes
- visible state
- persistent memory
- no unnecessary cloud dependency
- automation should save time, not create more work
